# المنطقة المحظورة — تصريح دخول

نسخة موقع عربية بثيم أسود وأحمر مستوحى من البوستر المرفق. يسمح للعوائل بالتسجيل في قائمة الانتظار، ثم يوزّع المنظم 8 عوائل على كل فعالية أسبوعية، ويسجل الأول والثاني في مسارين منفصلين. حد المشاركة فرصتان لكل عائلة. لا يمنح التسجيل مقعدًا تلقائيًا.

## تشغيل الموقع للجميع
1. أنشئ مشروع Supabase في https://supabase.com ثم نفّذ محتوى `schema.sql` من SQL Editor.
2. أنشئ مستخدمًا للإدارة في Authentication > Users. انسخ UUID ونفّذ `insert into public.admins(user_id) values ('UUID');` في SQL Editor.
3. من إعدادات API انسخ Project URL و publishable/anon key إلى `config.js`. **لا تستخدم مفتاح service_role**.
4. انشر ملفات `index.html`, `app.js`, `config.js` ومجلد `assets` على GitHub Pages أو Netlify.
5. افتح رابط الموقع، وسجّل الدخول من لوحة الإدارة لإنشاء فعاليات الثلاثاء والأربعاء وتوزيع العوائل وإدخال النتائج.

## ملاحظات
- لم يُربط الموقع بحساب Supabase فعلي، ولم يُنشر بعد. يحتاج المستخدم إلى حساب قاعدة بيانات واستضافة.
- لا توجد كلمة مرور إدارة افتراضية، وهي تُدار عبر Supabase Auth.
- صورة الخلفية مستوحاة مباشرة من صورة البوستر المرسلة، ويُفضّل استبدالها لاحقًا بخلفية نظيفة خالية من النصوص.
- قبل الاستخدام العام، فعّل مكافحة التسجيلات المزعجة (CAPTCHA/rate limiting)، وأضف سياسة خصوصية لبيانات المنسقين.
